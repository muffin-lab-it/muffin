## 확인 방법

개발 서버 `/preview/report`에서 금리·엔화·물가·긴 제목과 PC·390·360·두 열을 선택합니다. `?canvas=1&sample=rate`는 확인 도구를 뺀 사용자 화면입니다. 운영에서는 이 개발 경로가 404입니다.

모든 값은 화면 확인용 고정 데이터입니다. 실제 API·유료 모델을 호출하지 않습니다. 원본을 별도 실행한 로컬 환경에서는 3002의 `/preview/original`에서 최초 화면, `/preview/report?sample=rate`에서 같은 금리 예시를 비교합니다.

| 요구사항 | 반영 및 확인 |

| 요약 연보라 영역 복원 | 요약 연보라 배경. 모바일 머핀은 문장 아래 중앙에 160×144px 영역으로 크게 배치 |
| 숫자 영역 구분 | 숫자마다 옅은 회색 배경·중립색 테두리. PC 금리 3열 / 모바일 1열 |

| 검증 표시 기본 ON | 표시 전환 버튼 삭제. 검증 상세는 하단 접힘 |

| 출처·추천 | 출처 토글 삭제, 항상 표시. 추천은 기본 펼침 |

| 후속 추천 | 작성과 화면이 같은 지원 질문 목록 사용, 질문에 맞는 area 전달. 클릭 후 홈에서 질문·금리 선택 확인, 생성은 사용자가 굽기 클릭 |

## 검증 및 한계

- TypeScript·ESLint 및 전체 72개 파일 / 1,009개 테스트 통과.
- 유료 생성은 실행하지 않았으므로 추천의 실제 조회 성공이나 모델 출력 품질을 보장하는 QA는 아닙니다.
- 이전 실제 생성 평가에서 발견된 엔화 단위 검증 오인과 금리 계산 방향 불일치는 이번 UI 통과로 해결됐다고 간주하지 않습니다.
- 물가 품목군 가로 막대 및 요약 아래 숫자/출처 집계 한 줄은 초기 피드백의 선택 항목으로 이번 범위에 포함하지 않았습니다.
- 원본 문구 수정은 write.ts, depth.ts와 macro note, cpi.ts의 근사치 설명에 한정합니다. 스키마와 Agent 이름은 유지합니다.

## 카드 색감 복원

생활 영향·추천·차트 요약은 개별 카드에만 옅은 보라 배경과 테두리를 복원했습니다. 바깥 섹션과 안내에는 배경 상자를 추가하지 않아 3중 색칠을 피합니다. [모바일 생활 영향](tobe-impact-mobile.jpg). PC·390px 금리 캡처는 이 변경으로 갱신했으며 외화·두 열 캡처는 직전 QA 기록입니다.
